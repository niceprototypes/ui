The Chat page shows its parts (ChatComposer, ChatCopyAction, ChatMessage, ChatSuggestions, ChatThinking, ChatToolCall) in one API section, each part's props and examples under its name, instead of a section per part, so no part appears as its own entry in the nav or the Contents column. A catalog entry can set `partsSection` for a whole made of parts.
