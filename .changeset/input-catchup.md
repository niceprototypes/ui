"@niceprototypes/input": major

Input is field chrome around an input, select or textarea; status (base, disabled, error, success, warning) replaces state, filled replaces primary/secondary, backgroundColor and borderColor take colour tokens instead of raw CSS, and getInputToken is removed. Adds ref, as, start and end slots, width, rows, ghost, disabled, passwordReveal, Field wiring, aria-invalid on error, ARIA passthrough props, token-driven transitions, and a named Input export.
