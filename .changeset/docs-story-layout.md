Story layout: a story's text column ends with its values as code lines (`name="value"`, `// default` after the default one; display only, no copy), and its demo column holds only the demos, without the variant chips. ExampleBlocks takes `labels` (default on, for Storybook) and a new `ExampleValues` draws the lines; the docs site's Props lists and Examples sections use them.
