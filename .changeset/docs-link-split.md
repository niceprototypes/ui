Contents takes a `heading`: a row above the rows linking the section they belong to, spied and marked active like them. The docs site splits links between its columns, never listing one twice: the nav lists a page's top-level sections as leaves, and the Contents column lists the section in view's own sections under that section's name (the one link both show), both following one scroll-spy over the whole page.
