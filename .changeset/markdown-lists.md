Markdown lists start on the text edge: each item's marker at the list's start and its text the base gap after it (a numbered list's the large gap), the items the small gap apart. Markers are drawn, so lists render with `role="list"` to keep their list semantics; a numbered list counts from its `start`. Affects every Markdown consumer, ChatMessage replies included.
