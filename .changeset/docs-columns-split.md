DocsColumns `split`: how the columns share the width from laptop up, as named presets backed by `docsColumnsSplit` tokens: `even` (1:1, the default), `wideAside` (2:3) and `wideMain` (3:2). Named by column rather than side, so they hold in either writing direction. DocsPage sections take `split` too. Sticky, the gutter and the stacking breakpoint are the same for every split. The DocsColumns docs page demos each preset.
