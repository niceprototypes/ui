<Install package="badge" />

```jsx
import Badge from "@niceprototypes/badge"

<Badge status="success" label="Running" />
```

The tint, dot and text colours come from the `badge.*` tokens, which point at the semantic background and
text colours of each status, so the badge follows the day and night themes. The dot is decorative; the label
carries the meaning.
