<Install package="tree" />

```jsx
import { getTreeRows, TreeGuide } from "@niceprototypes/tree"

const rows = getTreeRows(items, {
  getId: item => item.id,
  getChildren: item => item.items,
  expandedIds,
  activeId,
})

rows.map(row => (
  <Row key={row.id} aria-level={row.depth + 1}>
    <TreeGuide {...row.guide} />
    {row.item.name}
  </Row>
))
```

TreeGuide renders the row's indent in flow and draws over the full height of its nearest
positioned ancestor, so the row (a flex row, a list item or a table cell) needs
`position: relative`, and consecutive rows must touch for the lines to join. It reads the Tree
tokens: `tree.guide.color`, `tree.guide.width`, `tree.guide.arm`, `tree.icon.size`,
`tree.icon.gap` and `tree.activeColor`.
