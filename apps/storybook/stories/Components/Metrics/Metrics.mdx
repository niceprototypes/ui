<Install package="metrics" />

```jsx
import Metrics from "@niceprototypes/metrics"

<Metrics value="2.5 GB/s" label="Decode throughput, measured natively" />
```

The value is a large Ink with `code` (the `ink.fontFamily:code` font); the label is a small Ink in the `ink.fontFamily:base` font.

`maxWidth` caps the label's width (a CSS length; default the `metrics.label.maxWidth` token, 24ch). The label stays centred by auto inline margins.
